Sistema de Help Desk desenvolvido em Python, Tkinter e SQLite para gerenciamento de chamados internos.

O projeto foi criado com foco em simular uma aplicação corporativa utilizada por equipes de suporte técnico para registro, acompanhamento e resolução de incidentes.

# Funcionalidades

- Abertura de chamados

- Título convertido automaticamente para MAIÚSCULO

- Cadastro de descrição detalhada

- Definição de prioridade

Baixa
Média
Alta
Crítica

- Registro automático de data e hora de abertura

- Pesquisa por ID ou título

- Listagem de chamados

- Visualização detalhada por duplo clique

- Alteração de status para "Resolvido"

- Persistência de dados utilizando SQLite

🛠️ Tecnologias Utilizadas
Python 3
Tkinter
SQLite
Datetime
